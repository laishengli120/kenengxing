# 可能性辅助教学摸球游戏

一个面向小学数学“可能性”教学的 3D 摸球模拟游戏。教师可以设置不同颜色球的数量，让学生观察随机抽取结果和统计次数，直观理解概率、随机性和样本次数之间的关系。

## 功能

- 3D 透明袋和球体动画展示
- 支持设置红球、黄球、绿球数量
- 支持单次或批量摸球
- 实时统计总次数和各颜色出现次数
- 清空统计后重新实验
- 适合课堂演示、互动提问和概率启蒙

## 技术栈

- 原生 HTML / CSS / JavaScript
- Three.js r128
- Google Fonts

## 使用方法

直接打开 `index.html` 即可运行。项目不需要构建工具和后端服务。

课堂使用建议：

1. 先设置明显不均衡的球数，让学生预测哪个颜色更可能出现。
2. 用少量次数演示随机波动。
3. 用较多次数批量抽取，观察结果逐渐接近数量比例。
4. 调整球数，讨论“可能”“不可能”“一定”和“可能性大小”。
